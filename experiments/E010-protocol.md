# E010: compact expansion with ten policies and a shared metric suite

Frozen 2026-10-29 before outcomes. User requested a broad main table and more
plots, then explicitly preferred more metrics over many expensive experiments.
No new model calls are needed for this expansion. E003's 310 actual model
outcomes remain an independent, separately reported endpoint.

## Fresh-seed policy evaluation
Use seeds 10000..10039, disjoint from E001/E009's 0..99, with the same three
sales generators. Convert SQL results to the same declared Boolean questions
as E009: East among leading regions; customer count >=6; threshold count >=5.
There are 120 tasks, 16 possible hidden worlds each, and ten fixed policies.
This is a fresh-seed check in the same generator families, not a new external
benchmark or confirmation of an established novel method.

Policies: anchor answer; ungated ask-all; full-map EC2; full-map EC2 with local
relevance filtering; four-cell bound with fixed/witness acquisition; partition
bound with fixed/witness acquisition; immediate local witness with fixed/witness
acquisition. These are controls and ablations, not ten independent published
algorithms. No changes are tuned to the new outcomes.

Primary metric: mean counted counterfactual executions. Main table columns:
method, answer accuracy, executions, questions, truly irrelevant question rate,
questions lacking an already observed local witness, valid stopping certificate
rate, E+Q, E+10Q, policy CPU milliseconds. All ten rows use the same 1,920 hidden
world episodes. A query-free method has undefined question-conditional rates
(report a dash), not a 0% rate suggesting successful interaction.

Truth maps are generated by actual SQLite queries once and reused by the
evaluation harness. Every policy callback is charged one logical execution;
duplicate callbacks are rejected. Policy CPU timing excludes truth construction
and post-hoc audit, and is not end-to-end SQL/API latency. Full-map policies are
charged all 16 labels. Truth labels enter only the post-hoc audit or an explicitly
charged callback. Questions require context-matched observed witnesses for
the strict policies. The ungated controls deliberately expose violations.

Report per-task averages over all hidden worlds. Resample 40 seed clusters,
retaining the three families and paired methods, for descriptive 95% percentile
intervals (2,000 draws, seed 20261029). No multiple-comparison significance
claims. Cost curves reuse E and Q with declared hypothetical weights.

## Small mechanism stress panel
Six controlled families, eight seeds 20000..20007 each, four bits: constant,
single active coordinate, nuisance plus XOR, rare conjunction, threshold, and
intent-dependent branch. Evaluate all 16 hidden worlds and all ten policies.
Report separately from sales averages. This explicitly includes cases absent
from the original sales pilot; it is not natural anomaly prevalence.
